## 一、结构体 struct：没有 class，就用 struct

学 C 和 C++ 的时候我就觉得，类型和结构体重合度有点高。Rust 也一样：没有 class，定义自己的类型就用 struct。

```rust
struct User {
    active: bool,
    username: String,
    email: String,
    sign_in_count: u64,
}

let user1 = User {
    active: true,
    username: String::from("someusername123"),
    email: String::from("someone@example.com"),
    sign_in_count: 1,
};
```

> 官方文档（第 5.1 节）："A struct, or structure, is a custom data type that lets you package together and name multiple related values that make up a meaningful group."——struct 是把多个相关值打包、命名成一个有意义的整体的自定义类型。

> [!warning] 3.14 注：上面那句"Rust 没有类型机制"说法不太对——Rust 不是没有类型机制，它的类型系统很强；没有的是 class，struct 就是定义新类型的方式之一。

### impl：方法和结构体关联起来

结构体中比较关键的是，Rust 用 `impl` 实现了方法和结构体的关联。

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

let rect = Rectangle { width: 30, height: 50 };
rect.area();
```

> 官方文档（第 5.3 节）："Methods are similar to functions: we declare them with the fn keyword and a name, they can have parameters and a return value, and they contain some code that's run when the method is called from somewhere else. Unlike functions, methods are defined within the context of a struct (or an enum or a trait object)..."——方法就是定义在 struct（或枚举、trait 对象）上下文里的函数。

### 构造函数 new：没有自动生成，手动写

对于构造函数，Rust 和别的语言相比略显麻烦：构造函数也是一种方法（废话）。因此需要用 `impl` 进行关联，同时 Rust 没有自动生成构造函数的语法，所以需要手动构建和命名 `new` 方法。

```rust
impl Rectangle {
    fn square(size: u32) -> Self {
        Self {
            width: size,
            height: size,
        }
    }
}

let sq = Rectangle::square(3);
```

> 官方文档（第 5.3 节）："Associated functions are often used for constructors that will return a new instance of the struct. These are often called `new`, but `new` isn't a special name and isn't built into the language."——关联函数常被用作构造函数，习惯上叫 `new`，但 `new` 不是关键字，也不是语言内置的。

> [!warning] 3.14 注："好像有的可以引用库函数实现"——标准库没有自动生成构造函数的功能；第三方 derive 宏（比如 `derive-new`）可以帮你生成，但那是外部 crate，不是 Rust 自带的。

## 二、没有默认参数和重载：用 Option<T> 顶上

Rust 的方法比较麻烦的一点是，你没法像 Python 那样给参数设默认值，想偷懒就得另想办法。

首先，Rust 在调用方法的时候要求必须传入所有参数（Python 就不一样，可以选择性传入，没有就用默认值）。要实现 Rust 的可选参数，就必须使用 `Option<T>`（一种枚举，后面会讲），调用时传 `None`，然后再在方法里判断（不知道这样会不会比较麻烦）。

```rust
fn greet(name: Option<String>) -> String {
    match name {
        Some(n) => format!("你好，{n}"),
        None => String::from("你好"),
    }
}

greet(Some(String::from("sisyphus")));
greet(None);
```

同时，Rust 的类型和方法也没有重载机制。

> [!warning] 3.14 注："后续会用泛型解决"这个说法不太准——泛型 ≠ 重载。重载是"同名函数按参数类型分发"，Rust 没有这个；泛型是"一个函数适配多种类型"，编译器按实际用的类型生成实现。想对不同类型做不同行为，靠的是 trait，不是泛型本身。

## 三、枚举 enum：变体也能带数据、带方法

基本的就不讲了，和别的语言类似。使用起来大概是 `XXX::AAA`、`XXX::BBB`、`XXX::CCC`。

枚举厉害的地方在于，变体可以携带不同类型的数据：

```rust
enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
}

let home = IpAddr::V4(127, 0, 0, 1);
```

> 官方文档（第 6.1 节）："Enums allow you to define a type by enumerating its possible variants."——枚举通过列举可能的变体来定义一个类型。

同样归功于强大的类型系统，枚举也可以通过 `impl` 绑定自己的方法：

```rust
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}

impl Message {
    fn call(&self) {
        // 方法体
    }
}

let m = Message::Write(String::from("hello"));
m.call();
```

> 官方文档（第 6.1 节）："Just as we can define methods on structs, we can also define methods on enums."——就像可以给结构体定义方法一样，也可以给枚举定义方法。

### Option<T>：Rust 的"没有值"

`Option<T>`，刚刚提到了，这是一个枚举，有两种变体：一种是 `None`，一种是 `Some(T)`，`Some` 里装一个 T 类型的值。

```rust
enum Option<T> {
    None,
    Some(T),
}
```

Rust 中没有 null，而是用一个枚举来表示"没有值"。可以说确实消灭了很多空指针的问题。

> 官方文档（第 6.1 节）："Rust does not have nulls, but it does have an enum that can encode the concept of a value being present or absent. This enum is `Option<T>`..."——Rust 没有 null，但它有一个枚举，可以表达"值存在或不存在"的概念，这就是 `Option<T>`。

用 `match` 判断 Option 是最常见的写法：

```rust
fn plus_one(x: Option<i32>) -> Option<i32> {
    match x {
        None => None,
        Some(i) => Some(i + 1),
    }
}
```

## 小结

- struct 是 Rust 里定义自己类型的方式，没有 class；`impl` 把方法和类型关联起来。
- `new` 只是约定俗成的关联函数名，Rust 不自动生成构造函数。
- 没有默认参数和重载；可选参数用 `Option<T>` + `None` 顶上。
- 枚举的变体可以带数据，也能有自己的方法；`Option<T>` 就是靠枚举消灭 null 的。
